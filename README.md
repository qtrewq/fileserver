# FileServer

A modern, secure file management system with real-time collaboration features.

- **[Installation Guide](docs/INSTALLATION.md)**: How to install on Windows, Linux, and Docker.
- **[User Guide](docs/USER_GUIDE.md)**: How to use the Dashboard, share files, and use the Admin Panel.
- **[Python Client Guide](docs/PYTHON_CLIENT.md)**: How to access your files programmatically with Python.
- **[Troubleshooting](docs/TROUBLESHOOTING.md)**: Common errors and fixes.

## Quick Start (Windows)

1. Download and run `FileServerSetup.exe`.
2. Open `http://localhost:30815`.
3. Login with `admin` / `adminpassword`.

## Features
- 🔐 User/Group Management
- 📁 File Upload/Download/Sharing
- 🤝 Real-time Code Editing
- 🚀 Python Script Execution
- 📊 Storage Quotas
